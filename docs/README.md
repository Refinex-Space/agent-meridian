# 文档

AgentMeridian 的所有设计与决策文档都在这里。动手写代码前，先读架构设计；要改动它，走 ADR。

| 目录 | 内容 | 什么时候读 |
|---|---|---|
| [architecture/](architecture/architecture.md) | 架构设计，项目唯一的架构基线 | 开工前必读；实现任何模块前读对应章节 |
| [research/](research/tech-selection.md) | 技术选型调研：候选框架、评估依据、被否决的方案 | 想知道"为什么选它"时 |
| [adr/](adr/README.md) | 架构决策记录：流程、模板、ADR-0020 起的新决策 | 要改动架构基线时 |
| [poc/](poc/README.md) | M0 技术验证的跟踪表与验证报告 | M0 期间；评审验证结论时 |

## 文档约定

- 架构设计与调研报告以中文撰写；代码、命令、配置、类名保持原文。
- 架构设计与本目录其他文档冲突时，以架构设计为准；发现冲突就提 ADR 修正。
- 改动架构基线的流程：提 ADR → 评审通过 → 修改 `architecture/architecture.md` 并递增版本号 → 再改代码。
- 新文档放进上表对应的目录；不属于任何目录的，先在这里加一行说明再建目录。
