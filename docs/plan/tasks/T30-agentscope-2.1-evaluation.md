## 背景与目标

平台锁定 AgentScope 2.0.4（ADR-0001、ADR-0003）。架构设计计划在 M2 评估升级到 2.1：2.1 带来了 `AgentSession`、Session Log 与 checkpoint、`ContextPolicy` 与 `ContextManifest`、工具搜索，并把 MCP SDK 升到 2.x。这些能力可能替换平台自研的部分，也可能带来破坏性变更。

本任务只做评估与验证，**不合并任何升级代码**。结论以 ADR 提议的形式交给用户决定。

## 必读

1. 开工检查中先确认 2.1 正式版已经发布（查看 Maven Central 与 GitHub Release）。未发布时，停止并报告。
2. AgentScope 2.1 的发布说明、迁移指南、变更日志；2.0.4 与 2.1 之间的源码差异（`git diff v2.0.4 v2.1.x`，聚焦 core 与 harness 的公开 API）。
3. 架构设计中所有引用 AgentScope 2.0.4 行为的章节，以及 `meridian-engine-agentscope` 的 `CLAUDE.md` 中的易错点。

## 范围

### 要做

- **差异清单**：平台用到的每个 AgentScope API（从 `meridian-engine-agentscope` 的代码中逐一列出），在 2.1 中是保留、变更、废弃还是删除。
- **机会评估**：2.1 的新能力能否替换平台的自研实现，例如会话队列与 steer、checkpoint、上下文构成记录、工具搜索；每项给出收益、风险、改动量。
- **验证分支**：在一个 git worktree 中把依赖升到 2.1，修到能编译，跑全部测试（含 `-Plive`、`-Pkind`），记录失败项与原因。这个分支不合并。
- **依赖影响**：MCP SDK 升到 2.x 后，T10b、T19 的 MCP 实现需要的改动；Spring Boot 版本的兼容性。
- **ADR 提议**：`docs/adr/` 下新增一份 ADR，状态"提议"，给出"升级、暂缓、部分采纳"的建议与理由。

### 不做

- 合并升级。用户采纳 ADR 后，另起任务实施。
