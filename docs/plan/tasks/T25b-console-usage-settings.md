## 背景与目标

本任务完成控制台最后两个一级导航：用量与预算、设置。完成后，架构设计「控制台」信息架构中的全部页面都可用。

这两组页面承载了控制台中最多的不可逆操作：吊销 API Key、移除成员、修改预算硬阈值。后果提示与确认方式必须严格按规范执行。

## 必读

2. 架构设计「控制台」信息架构、「计量与预算」、「安全架构」中的 API Key 与成员角色、「API 设计」中的 Webhook。

## 范围

### 要做

- **用量与预算**：用量趋势（按天、模型、智能体、API Key）、明细表、导出 CSV；四级预算的设置、软硬阈值、告警历史。
- **设置**：成员与角色（按 T19b 定义的语义添加成员、修改角色、移除）、API Key（创建时明文只显示一次并提示保存、作用域、吊销需输入名称确认）、通知地址（Webhook 的增删改、签名密钥、投递记录与重投）、租户设置（租户级系统提示词、联网搜索后端）、审计日志（筛选与详情）。

### 不做

- M2 的能力（预算报表的高级分析等）。

## 实现要点

- 金额与 token 按规范格式化；用量口径（是否含缓存 token、价格表版本）在 info 提示中说明。
- API Key 创建对话框：明文只显示一次，提供复制并提示"关闭后无法再次查看"；关闭后从内存中清除。
- 危险操作统一使用 `DangerConfirmDialog`，写明后果。
