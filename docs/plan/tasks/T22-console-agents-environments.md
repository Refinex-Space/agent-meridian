## 背景与目标

智能体开发者在这里定义、发布、管理智能体，在环境页配置执行档位与出网白名单。智能体定义是控制台里最复杂的表单：系统提示词、模型、工具、MCP、技能、子智能体、权限策略、知识库、压缩与计划模式。要让开发者既能完整配置，又不被信息淹没。

## 必读

1. `docs/engineering/frontend-design.md`（页面模板中的"列表页""详情页""编辑页"、交互规范、状态与反馈）。
2. 架构设计「领域模型」、「控制台」中智能体与环境两行、「运行时架构」中「权限判定」与「子智能体」（理解配置项的含义）。
3. `console/CLAUDE.md`、T20c 中智能体编辑的原型。
4. `meridian-api/src/main/resources/schema/agent-spec.schema.json` 与管理 API 中智能体、环境的接口。

## 范围

### 要做

- 智能体列表页、详情页（概要、版本历史、使用中的会话）、编辑页。
- 编辑页分组：基本信息、模型（主模型与备用模型）、系统提示词（Monaco，Markdown）、工具（平台工具、MCP 工具、自定义工具说明）、技能、子智能体、知识库与前置检索、权限策略（规则编辑器与模式）、上下文（压缩阈值）、计划模式。表单校验与智能体规格的 JSON Schema 一致。
- 版本：发布（发布前展示与上一版本的差异）、版本对比、基于某版本创建新草稿。
- 子智能体拓扑：xyflow 展示主智能体与子智能体的关系、各自的工具集。
- 环境列表、编辑页：档位、规格、出网白名单（域名列表的校验与说明）、修订历史。
- 删除与归档：按 `DangerConfirmDialog` 写明后果（例如有多少会话在用）。

### 不做

- 能力、模型、凭据页面（T23）。

## 实现要点

- 权限规则编辑器：规则内容的语法因工具而异（路径 glob、命令前缀、域名），编辑器根据所选工具提示正确的格式，并做本地校验。
- 未保存离开提示；保存栏固定在底部。
- 智能体规格中引用的资源（模型、技能、知识库、MCP 服务）用可搜索的选择器，显示资源当前状态（例如 MCP 服务不可用）。

## 验收标准

- [T22-A01] 从零创建一个智能体（含工具、技能、子智能体、权限规则、知识库）并发布，用它在 Playground 外通过 API 创建会话成功。验证：Playwright 用例加 API 调用。
- [T22-A02] 表单校验与 JSON Schema 一致：非法配置（例如子智能体工具超出父智能体）在本地被拦截，服务端校验错误也能定位到字段。验证：组件测试与 Playwright 用例。
- [T22-A03] 发布前展示版本差异；版本对比页正确显示差异。验证：Playwright 用例与截图。
- [T22-A04] 子智能体拓扑图正确反映配置。验证：截图。
- [T22-A05] 环境的出网白名单校验生效，修改后修订号递增。验证：Playwright 用例。
- [T22-A06] 所有页面的加载骨架、空态、错误态、无权限状态都已实现，与 T20c 原型一致，内容区以外与 T21 的截图基线（`toHaveScreenshot`）一致。验证：亮暗主题与两种宽度的截图（`tmp/evidence/T22/`）与 `toHaveScreenshot` 结果，对照评审表与禁用清单。
- [T22-A07] 用 `ego-browser` 做一次完整走查：以开发者身份完成"创建、发布、对比、回滚为新草稿"流程，记录发现的问题并修正。验证：走查记录。
- [T22-A08] 控制台全部检查与 `scripts/dev/verify.sh` 通过。验证：命令输出。
