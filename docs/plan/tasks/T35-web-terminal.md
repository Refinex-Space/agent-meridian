## 背景与目标

开发者调试沙箱档的会话时，需要直接进入会话的沙箱查看文件、运行命令。Web 终端在控制台中提供一个连接到会话沙箱的交互式终端。它绕过了智能体的权限体系，所以只对有权限的角色开放，并全程审计。

## 必读

1. 架构设计「工作区与沙箱」「安全架构」、「控制台」中的 Web 终端。
2. `sandbox-runtime/` 的执行服务与 `docs/engineering/frontend-design.md`。

## 第一步：设计增补

`docs/architecture/addenda/M2-Web终端.md`：

- 连接链路：浏览器（xterm.js）↔ runtime（WebSocket，OIDC 认证）↔ 沙箱执行服务（PTY 接口，需要在 `sandbox-runtime` 中新增）。
- 权限：哪些角色可以使用；会话正在运行时是否允许（与智能体并发操作同一工作区的风险）。
- 审计：记录连接、断开、输入的命令（考虑是否记录完整的输入输出流及其存储成本）。
- 空闲超时、连接上限、沙箱回收与终端连接的关系（有终端连接时不回收）。
- 与基线的关系：只补充；需要改动基线时写 ADR 提议并停止。

**设计关口**：设计增补提交后，把看板中本任务的状态改为"阻塞（等待用户确认设计增补）"，在报告中列出需要用户判断的设计取舍，然后停止（`docs/plan/protocol.md`「设计增补关口」）。用户确认后，用同一个任务编号新开会话续做实现。

## 验收标准

- [T35-A01] 设计增补已写，用户已确认。验证：文件路径与确认日期。
- [T35-A02] 有权限的开发者在控制台打开终端，执行命令并看到输出；窗口大小同步。验证：Playwright 用例（`kind`）。
- [T35-A03] 没有权限的角色无法建立连接；令牌过期后连接被断开。验证：测试。
- [T35-A04] 连接与命令都有审计记录。验证：测试。
- [T35-A05] 空闲超时断开；有终端连接时沙箱不被回收。验证：测试。
- [T35-A06] 终端面板通过截图评审。验证：截图与评审记录。
- [T35-A07] 全部质量门禁通过。验证：命令输出。
