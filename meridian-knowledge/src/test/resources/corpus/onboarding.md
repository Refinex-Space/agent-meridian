# 新员工入职指南

欢迎加入示例科技。本指南说明入职第一周需要完成的事项、常用系统的开通方式与考勤规则，请在入职当天通读。

## 一、入职前准备

入职前请准备好身份证、学历学位证书、离职证明与近期体检报告的原件和复印件。人力资源部会在入职前三个工作日通过邮件发送报到通知，写明报到时间、地点与联系人。

### 1. 需要提交的材料

- 身份证原件与正反面复印件一份
- 最高学历与学位证书原件及复印件
- 上一家单位出具的离职证明
- 三个月内的入职体检报告
- 本人名下的工资卡开户行与卡号

### 2. 报到流程

1. 到前台登记并领取临时门禁卡
2. 与人力资源专员签订劳动合同与保密协议
3. 领取办公设备并在资产管理系统中确认
4. 由部门导师带领熟悉办公区域与团队成员

## 二、常用系统

公司使用统一身份认证，入职当天信息技术部会开通以下系统的账号。首次登录需要修改初始密码，并绑定手机令牌。

| 系统 | 用途 | 开通方式 |
| --- | --- | --- |
| 企业邮箱 | 内外部邮件往来 | 入职当天自动开通 |
| 办公系统 | 请假、出差、报销审批 | 入职当天自动开通 |
| 代码仓库 | 研发岗位的代码管理 | 部门负责人提交申请 |
| 知识库 | 公司制度与项目文档 | 入职当天自动开通 |

## 三、考勤与休假

公司实行弹性工作制，核心工作时间为上午十点至下午四点，每日工作时长不少于八小时。上下班需要在办公系统中打卡，外出办事应当提前提交外出申请。

### 1. 年假

员工入职满一年后享受带薪年假，年假天数按照累计工作年限确定：累计工作满一年不满十年的，年休假五天；满十年不满二十年的，年休假十天；满二十年的，年休假十五天。

### 2. 病假与事假

病假需要提供二级以上医院出具的诊断证明，事假需要提前一个工作日申请。连续请假超过三天的，需要部门负责人与人力资源部共同审批。
